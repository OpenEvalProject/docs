# OpenEval Docs

Public archive for OpenEval posters, talks, papers, and related presentation
materials.

## Folder convention

Each event or document lives in its own top-level folder:

```text
YYYYMMDD-AuthorInitials-ShortName
```

For example:

```text
20260526-BLP-CSHL_AI_IN_BIOLOGY
```

Each folder should include the final rendered artifact, source files needed to
edit it, and a short README describing how it was generated.
